# Security Policy

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

Contact the maintainers privately through GitHub Security Advisories or the repository owner's preferred contact channel.

Please include:

- Affected version
- Steps to reproduce
- Impact description

## Scope

This project stores local files and uses a local SQLite database. The embedded server should only be exposed to `127.0.0.1` unless you intentionally configure it otherwise.
