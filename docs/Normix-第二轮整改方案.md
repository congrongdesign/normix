# Normix 第二轮整改方案

## 1. 整改目标

本轮只解决两个问题：

1. 作品库卡片信息过多、标签不突出、悬浮按钮干扰、比例偏竖。
2. 灵感集文件夹筛选路径过长，需要反复打开组织面板。

## 2. 作品库卡片整改

### 2.1 卡片信息结构

新卡片只保留 4 个信息层：

```text
封面 16:9
标题 + 收藏
分类/类型 · 页数
彩色标签
```

移除：

- 文件大小。
- 悬浮“预览 / 选择”按钮。
- 多行重复元数据。

### 2.2 标签颜色

标签使用稳定的浅色强调体系：

| 色相 | 文字色 | 背景色 | 适用 |
| --- | --- | --- | --- |
| 青绿 | `#0F766E` | `#CCFBF1` | 通用主题 |
| 琥珀 | `#B45309` | `#FEF3C7` | 重点/比赛 |
| 绿色 | `#15803D` | `#DCFCE7` | 完成/分类 |
| 玫红 | `#BE123C` | `#FFE4E6` | 强调/活动 |
| 橙色 | `#C2410C` | `#FFEDD5` | 风格/标签 |
| 蓝灰 | `#475569` | `#E2E8F0` | 中性标签 |

颜色按标签名稳定生成，同一个标签颜色始终一致，不随刷新变化。

### 2.3 卡片交互

- 单击：选择。
- Ctrl/Shift：多选。
- 双击：打开预览。
- 右键：菜单操作。
- 悬浮：只有轻微上移和阴影，不再出现按钮。

### 2.4 卡片比例

- 封面比例：16:9。
- 卡片信息区：单行主信息 + 标签。
- 卡片高度由封面主导，不再被文字区撑高。

## 3. 灵感集筛选整改

### 3.1 顶部筛选栏增加文件夹

新筛选栏：

```text
[组织] [搜索] [颜色] [版式] [文件夹] [标签] [评分]
```

- 文件夹直接使用下拉筛选。
- 选择文件夹后立即过滤图片。
- 不需要打开组织面板。

### 3.2 组织面板只做管理

组织面板只保留：

- 新建文件夹。
- 重命名。
- 删除。
- 拖拽排序。
- 标签分组管理。

不再承担“高频筛选”职责。

### 3.3 当前筛选状态可视化

当前选中的文件夹、标签、颜色、版式都直接显示在顶部筛选栏中，用户一眼可知当前过滤条件。

## 4. UI 黄金法则落地

| 法则 | 本轮落地 |
| --- | --- |
| 一致性 | 卡片、标签、筛选栏样式统一 |
| 极简减负 | 删除重复元数据和悬浮按钮 |
| 层级优先级 | 标题 > 标签 > 分类/页数 |
| 直观可预判 | 文件夹筛选直接放在顶部 |
| 及时反馈 | 选择文件夹立即刷新结果 |
| 容错防错 | 双击预览、单击选择，操作不会误触 |
| 适配兼容 | 卡片 16:9，移动端保持单列 |
| 留白呼吸 | 删除冗余信息，卡片更轻 |
| 可读性优先 | 标签文字对比度达标 |
| 场景适配 | 工具型界面，黑白灰为主 |

## 5. 实施范围

### 已完成

- 作品库卡片删除悬浮按钮。
- 卡片元数据精简为一行。
- 标签增加稳定彩色强调。
- 封面调整为 16:9。
- 灵感集顶部增加文件夹筛选。
- 组织面板保留为低频管理入口。

### 后续可选

- 将相同标签颜色应用到标签树。
- 增加暗色模式适配。
- 统一特殊状态页面的视觉样式。

## 6. 验收标准

- 作品库卡片不再出现“预览 / 选择”按钮。
- 卡片不再重复展示文件大小。
- 标签颜色稳定、文字清晰。
- 卡片比例更横向、更平衡。
- 灵感集不打开组织面板即可筛选文件夹。
- 组织面板只用于管理，不再承担高频筛选。
- 桌面和移动端均无布局溢出。
- `lint`、`build`、`smoke`、`acceptance` 全部通过。

## 7. 风险控制

- 不删除作品库的批量操作、检查器、右键菜单。
- 不删除文件夹新建、重命名、删除、拖拽能力。
- 不删除标签分组、删除、筛选能力。
- 只做信息收敛和交互路径优化。

## 8. 灵感集组织面板右置

### 8.1 目标

- 灵感集去掉右侧检查器。
- 标签管理入口放到顶部菜单栏。
- 组织面板回到左侧，常驻显示。
- 顶部不再需要“组织”按钮。

### 8.2 新布局

```text
[主导航] [组织面板] [页面内容]
                [标签管理]
```

- 组织面板常驻左侧。
- 包含文件夹管理、标签管理。
- 页面内容区保持完整浏览。
- 标签管理按钮保留在顶部筛选/菜单栏。
- 移动端组织面板自动移到内容下方。

### 8.3 交互变化

- 不再需要点击“组织”按钮。
- 页面双击仍可打开大图预览。
- 页面标签、文件夹筛选仍可从顶部筛选栏直接操作。
- 作品详情、页面详情由预览查看器承接，不再使用右侧检查器。

### 8.4 验收

- 灵感集顶部无“组织”按钮。
- 左侧为组织面板。
- 右侧无检查器。
- 顶部菜单栏有“标签管理”入口。
- 移动端无横向溢出。
