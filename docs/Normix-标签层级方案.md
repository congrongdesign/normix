# Normix 标签层级方案

## 1. 目标

作品分类标签不是平铺的，而是有层级关系。例如：

```text
比赛
├── 职规赛
├── 教创赛
└── 国创赛
    ├── 新工科
    ├── 高教主赛道
    └── 红旅赛道
```

这个方案让标签既能“分比赛”，也能“分比赛下的类别”。

## 2. 数据结构

使用已有标签树结构：

- 一级节点：比赛。
- 二级节点：职规赛、教创赛、国创赛。
- 三级节点：新工科、高教主赛道。

标签表已有 `parent_id`，支持无限层级：

```text
比赛 (id: A)
├── 职规赛 (parent_id: A)
├── 教创赛 (parent_id: A)
└── 国创赛 (parent_id: A)
    └── 新工科 (parent_id: 国创赛)
```

## 3. 创建层级

在“组织面板”中：

1. 右键空白区域，选择“新建分组”，创建一级“比赛”。
2. 右键“比赛”，选择“新建子分组”，创建“职规赛 / 教创赛 / 国创赛”。
3. 右键“国创赛”，选择“新建子分组”，创建“新工科”。

## 4. 移动层级

- 右键标签或分组，选择“移动分组”。
- 移动目标会展示完整分组树。
- 可以把“新工科”移动到“国创赛”下。
- 也可以移动到顶层，变成一级分类。

## 5. 标签挂接

- 页面只挂最终标签，例如“新工科”。
- 选中“国创赛”时，自动筛选其下所有子标签页面。
- 选中“比赛”时，自动筛选全部比赛相关页面。

## 6. 视觉区分

- 一级分组：文件夹图标，最外层。
- 二级分组：文件夹图标，缩进一层。
- 叶子标签：标签图标，带颜色。
- 分组与叶子标签样式保持区分。

## 7. 验收

- 可以创建三级及以上分组。
- 子分组可以移动到其他分组。
- 删除父分组不会删除子分组。
- 选择父分组会筛选所有子标签页面。
- 标签数量按页面数统计，不受层级影响。
