# Normix 标签统一管理方案

## 1. 目标

把“作品标签”和“页面标签”统一到一个管理面板中，同时支持层级分类。

示例：

```text
作品标签
└── 比赛
    ├── 职规赛
    ├── 教创赛
    └── 国创赛
        └── 新工科

页面标签
└── 页面类型
    ├── 封面
    └── 封底
```

## 2. 入口

- 作品库顶部：`标签管理`。
- 灵感集顶部：`标签管理`。

点击后打开统一标签管理面板。

## 3. 面板结构

### 3.1 两个页签

- 作品标签：管理挂到作品上的标签。
- 页面标签：管理挂到页面上的标签。

两者独立展示，但支持相同的管理操作。

### 3.2 支持操作

- 新建一级分组。
- 新建子分组。
- 重命名。
- 移动分组。
- 删除分组。
- 删除标签。

### 3.3 层级规则

- 一级分组：比赛。
- 二级分组：职规赛、教创赛、国创赛。
- 三级分组：新工科、高教主赛道。

删除父分组时，子分组保留并提升到上一级。

## 4. 卡片展示

作品卡片标签会展示层级路径：

```text
职规赛
国创赛 / 新工科
```

- 最外层分类作为辅助文字。
- 叶子标签使用彩色强调。
- 鼠标悬浮显示完整路径。

## 5. 数据关系

- 分组：只用于组织，不直接挂到作品或页面。
- 叶子标签：可以挂到作品或页面。
- 选择父分组时，自动筛选所有子标签。

## 6. 验收

- 作品库和灵感集都能打开标签管理。
- 作品标签与页面标签分开管理。
- 可以创建多级分组。
- 可以新建子分组并移动到其他分组。
- 卡片显示标签层级路径。
- 删除父分组不删除子分组。
