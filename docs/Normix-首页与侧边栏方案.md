# Normix 首页与侧边栏收缩方案

## 1. 目标

1. 左侧菜单新增“首页”。
2. 首页承担整体数据分析和上传作品入口。
3. 左侧栏支持展开/收缩。
4. 收缩后只显示小图标，不再占用大空间。

## 2. 左侧菜单结构

```text
展开状态
[Normix Logo]
首页
作品库
灵感集
回收站
导入作品
[收缩按钮]

收缩状态
[Logo 图标]
[首页图标]
[作品库图标]
[灵感集图标]
[回收站图标]
[导入图标]
[展开按钮]
```

## 3. 首页数据概览

首页默认展示以下模块：

### 3.1 顶部统计卡

建议使用 4 张统计卡：

| 指标 | 来源 |
| --- | --- |
| 作品总数 | `works.length` |
| 页面总数 | `works.flatMap(w => w.pages).length` |
| 文件夹数量 | `collections.length` |
| 标签数量 | `tagTree` 中叶子标签数量 |

统计卡样式：

```text
[图标] [数值] [说明]
```

数值使用 22-28px，说明使用 11-12px，保持黑白灰。

### 3.2 最近上传

按 `uploadedAt` 倒序展示最近 5 个作品：

- 封面缩略图
- 作品名
- 文件类型
- 上传时间

点击作品可进入作品详情。

### 3.3 作品类型分布

按 `work.kind` 统计：

- PPT
- PDF
- ZIP
- IMAGE

使用横向条形图或简单占比列表，不使用复杂图表。

### 3.4 文件夹分布

展示每个文件夹中的页面数量：

```text
文件夹名 页面数
```

点击文件夹可跳转到灵感集对应文件夹。

### 3.5 热门标签

统计作品标签出现次数：

- 按标签使用次数排序。
- 展示前 8 个标签。
- 标签使用彩色强调。

### 3.6 作品评分分布

统计：

- 未评分
- 1-2 星
- 3 星
- 4 星
- 5 星

用于判断素材质量。

### 3.7 上传作品入口

首页顶部保留主要上传入口：

```text
[导入作品]
```

也可以提供整页拖拽上传。

## 4. 首页布局建议

```text
[统计卡] [统计卡] [统计卡] [统计卡]

[最近上传] [作品类型分布]

[文件夹分布] [热门标签]

[评分分布]
```

桌面端采用 2 列布局。

移动端采用单列布局。

## 5. 首页无数据状态

当没有作品时：

```text
Normix Logo
还没有作品
导入你的第一个作品
```

点击后打开文件选择器。

## 6. 侧边栏收缩展开

### 6.1 默认状态

- 宽度：232px。
- 显示品牌、导航文字、导入文字。

### 6.2 收缩状态

- 宽度：72px。
- 只显示图标。
- 品牌只显示 Logo 图形。
- 导航只显示图标，悬浮时显示 Tooltip。
- “导入作品”只显示图标。

### 6.3 切换入口

- 展开状态：侧边栏底部或顶部显示收缩按钮。
- 收缩状态：显示展开按钮。

推荐位置：

```text
侧边栏最底部
[← 收缩] 或 [→ 展开]
```

### 6.4 状态持久化

将侧边栏状态保存到 `localStorage`：

```text
normix-sidebar-collapsed
```

刷新后保持上次状态。

### 6.5 动效

- 宽度过渡：160ms。
- 图标与文字淡入淡出：120ms。
- 不做复杂动画。

## 7. 首页数据来源

首页使用现有前端状态即可：

| 数据 | 来源 |
| --- | --- |
| `works` | 作品库数据 |
| `allPages` | 所有页面 |
| `collections` | 文件夹 |
| `tagTree` | 标签树 |
| `trashWorks` | 回收站数量 |

不需要新增数据库表。

## 8. 实施阶段

### Phase 1：侧边栏收缩

- 新增 `home` 导航项。
- 新增 `sidebarCollapsed` 状态。
- 新增收缩/展开按钮。
- 实现 232px / 72px 两种布局。

验收：

- 点击收缩后只显示图标。
- 点击展开后恢复完整状态。
- 刷新后保持状态。

### Phase 2：首页统计

- 新增首页视图。
- 实现顶部统计卡。
- 实现最近上传列表。

验收：

- 数据与作品库一致。
- 无作品时显示空状态。

### Phase 3：首页分布模块

- 实现类型分布。
- 实现文件夹分布。
- 实现热门标签。
- 实现评分分布。

验收：

- 所有模块数据准确。
- 点击标签/文件夹可跳转对应视图。

### Phase 4：上传入口

- 首页顶部保留“导入作品”。
- 支持拖拽导入。

验收：

- 上传后自动刷新首页统计。

## 9. 验收标准

- 左侧菜单新增“首页”。
- 首页展示作品数、页数、文件夹数、标签数。
- 首页展示最近上传、类型分布、文件夹分布、热门标签、评分分布。
- 首页有明确的上传入口。
- 侧边栏可收缩为 72px 小图标。
- 收缩后不占大空间。
- 收缩状态可展开。
- 收缩状态持久化。
- 移动端不破版。
