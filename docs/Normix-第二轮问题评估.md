# Normix 第二轮问题评估

## 1. 核心问题

第一轮整改解决了“四栏布局过复杂”的问题，但第二轮检查发现两个高频体验问题：

1. 作品库卡片信息重复、标签不突出、悬浮按钮多余、卡片比例偏竖。
2. 灵感集筛选仍需要反复打开“组织”面板，文件夹筛选和内容浏览被割裂。

## 2. 作品库卡片问题

### 2.1 信息重复

当前作品卡片同时展示：

- 分类/行业
- 文件类型
- 页数
- 文件大小
- 标签
- 标题
- 收藏状态
- 悬浮时的“预览 / 选择”按钮

其中文件类型、页数、文件大小都属于次要元数据，不应全部放在卡片第一视觉层。

建议卡片只保留：

- 标题
- 收藏状态
- 一个分类/类型信息
- 页数
- 彩色标签

文件大小保留在检查器中，不在卡片重复展示。

### 2.2 标签不够显眼

当前标签是浅灰底、浅灰字，在卡片上接近辅助文字，无法形成快速识别的信息点。

建议：

- 每个标签使用稳定的浅色底 + 深色文字。
- 标签颜色只用于强调，不改变整体黑白灰风格。
- 标签字体加粗，让用户一眼看出作品主题。

### 2.3 悬浮按钮多余

当前卡片悬浮时会出现“预览 / 选择”按钮。

问题：

- 点击卡片本身已经可以选择。
- 双击已经可以预览。
- 悬浮按钮增加视觉噪音，也让卡片高度不稳。

建议：

- 删除卡片内悬浮操作按钮。
- 只保留双击预览、单击选择、右键菜单。

### 2.4 卡片比例偏竖

当前卡片包含较多文字和操作区，视觉重心偏纵向。

建议：

- 封面使用 16:9 横向比例。
- 信息区只保留一行主信息 + 标签。
- 删除悬浮按钮后，卡片自然变矮、更平衡。

## 3. 灵感集筛选问题

### 3.1 需要反复打开“组织”面板

当前文件夹筛选放在“组织”面板中，用户每次切换文件夹都要：

1. 点击“组织”。
2. 在文件夹树中选择。
3. 回到图片区查看。

这个路径太长，也不符合“筛选是高频操作”的使用习惯。

### 3.2 筛选与管理职责没有彻底分离

- 筛选：应该发生在内容区顶部。
- 管理：才应该进入“组织”面板。

当前两者仍混在一起。

### 3.3 解决方案

把文件夹筛选直接放进灵感集顶部筛选栏：

```text
[组织] [搜索] [颜色] [版式] [文件夹] [标签] [评分]
```

- 点击“文件夹”下拉即可筛选，不需要打开组织面板。
- 组织面板只负责新建、重命名、删除、拖拽。
- 标签筛选已经在顶部，保持一致。

## 4. UI 全维度问题

| 模块 | 现状 | 问题等级 |
| --- | --- | --- |
| 视觉色彩 | 标签缺少强调色，状态色不明显 | 二级 |
| 布局间距 | 卡片信息区略高，封面比例偏竖 | 二级 |
| 文字字体 | 卡片元数据层级不够清楚 | 二级 |
| 按钮控件 | 悬浮“预览/选择”按钮多余 | 一级 |
| 图标图形 | 基本统一，无需大改 | 三级 |
| 交互体验 | 文件夹筛选需要反复打开组织面板 | 一级 |
| 适配兼容 | 当前无横向溢出，移动端正常 | 通过 |
| 特殊状态 | 空状态、加载状态基本完整 | 二级 |
| 合规规范 | 标签颜色需保证文字对比度 | 二级 |

## 5. 优先级

| 优先级 | 事项 |
| --- | --- |
| P0 | 删除卡片悬浮按钮 |
| P0 | 顶部直接筛选文件夹 |
| P1 | 卡片信息精简 |
| P1 | 标签彩色强调 |
| P2 | 卡片比例和间距微调 |

## 6. 结论

第二轮整改不是继续加功能，而是把第一轮已经简化的界面进一步做“信息减法”：

- 卡片只保留用户第一眼需要的信息。
- 标签用颜色成为视觉焦点。
- 高频筛选直接放在内容区，组织面板只留给低频管理。
