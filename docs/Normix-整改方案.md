# Normix 整改方案

## 1. 整改目标

在不删除现有功能的前提下，把 Normix 从“功能很多但界面很挤”调整为“功能完整但路径清晰”。

核心原则是奥卡姆剃刀：

> 如无必要，勿增实体。

最终目标是让用户打开后只看到一条清晰路径：

```text
1. 选择视图：作品库 / 灵感集 / 回收站。
2. 浏览内容：搜索、筛选、排序。
3. 需要时打开管理或详情。
```

## 2. 新布局原则

### 2.1 默认两栏，最多三栏

```text
默认状态
[主导航] [主内容区]
          [标题 + 筛选栏]
          [内容网格]

打开详情/管理时
[主导航] [主内容区] [辅助抽屉]
```

辅助抽屉只包括两种：

- 检查器：查看和编辑当前选中内容。
- 组织面板：管理文件夹、标签、分组。

两者不会同时默认打开。

### 2.2 核心内容宽度优先

1440px 桌面下，主内容区应至少占 65% 宽度。当前内容区仅约 42%，需要把常驻管理栏和常驻检查器取消。

### 2.3 一个概念只有一个主要入口

| 概念 | 主要入口 | 辅助入口 |
| --- | --- | --- |
| 文件夹 | 组织面板 | 页面面包屑 |
| 标签 | 组织面板 | 顶部标签筛选 |
| 导入作品 | 侧边栏 | 空状态 / 文件夹右键 |
| 作品详情 | 检查器抽屉 | 双击预览 |
| 批量操作 | 检查器抽屉 | 右键菜单 |

重复入口应删除，避免用户记忆多个位置。

## 3. 作品库整改方案

### 3.1 删除左侧管理栏

删除 `library-manage-rail`，不再默认显示“全部 / 收藏夹 / 文件夹 / 标签”这一栏。

保留能力：

- 顶部筛选栏提供“全部 / 收藏夹”等快速筛选。
- 文件夹和标签进入“组织面板”管理。
- 作品卡片继续展示收藏状态。

### 3.2 顶部筛选栏统一

新作品库顶部只保留一行核心操作：

```text
[视图/筛选] [搜索] [排序] [导入作品]
```

- 搜索：按作品名、文件名、标签搜索。
- 排序：最新 / 名称 / 页数 / 文件大小 / 评分。
- 标签：使用轻量弹层，不把完整标签树常驻在页面中。
- 导入：只保留侧边栏和空状态，顶部不再重复。

### 3.3 检查器改为抽屉

- 未选择任何作品时，不显示检查器。
- 点击作品后，右侧打开 360px 检查器。
- Esc 或点击空白关闭。
- 检查器内保留：预览、作品名、分类、标签、评分、页数、文件大小、创建时间、备注、文件夹、打开/复制/移动/导出/删除。

### 3.4 批量操作收敛

多选后只保留一个明确位置：

- 选中作品后，顶部出现批量操作条。
- 批量操作条包含：加分类、加标签、移动文件夹、评分、导出、移入回收站。
- 右键菜单保留常用快捷操作，但不再重复整个批量面板。

## 4. 灵感集整改方案

### 4.1 删除常驻文件夹栏

删除灵感集左侧的常驻“文件夹 + 标签 + 作品 Tab”结构。

新结构：

```text
[主导航] [筛选栏 + 页面内容]
          [当前路径：全部 / 文件夹 / 标签]
          [图片网格]
```

文件夹浏览通过顶部路径或“组织面板”进入。

### 4.2 组织面板

“组织面板”是唯一的文件夹和标签管理入口：

- 文件夹树：新建、重命名、删除、拖拽排序。
- 标签树：分组、重命名、删除、拖拽移动。
- 页面拖拽到文件夹时，自动打开组织面板作为放置目标。

组织面板打开后：

- 不遮挡整个页面。
- 支持 Esc 关闭。
- 移动端以底部抽屉形式出现。

### 4.3 标签筛选与管理分离

- 顶部标签筛选：只负责筛选，不提供新增、删除、分组。
- 组织面板：只负责管理，不承担主筛选职责。
- 点击标签筛选时，不打开组织面板。

这样可以消除当前“点击标签既像筛选又像管理”的歧义。

### 4.4 作品入口

灵感集不再保留“作品 Tab”。

作品由作品库管理；灵感集只负责页面级浏览和素材筛选。如果需要按作品进入，可通过顶部路径或作品库跳转。

## 5. 组件与代码简化

### 5.1 需要删除或合并的组件区域

| 当前区域 | 处理方式 |
| --- | --- |
| 作品库左侧管理栏 | 删除 |
| 灵感集左侧文件夹/作品 Tab | 合并到组织面板 |
| 顶部筛选栏中的导入按钮 | 删除，保留侧边栏与空状态 |
| 多选检查器中的批量面板 | 合并为顶部批量操作条 |
| 重复的标签筛选入口 | 只保留顶部标签筛选 |

### 5.2 需要保留的核心组件

- 主导航。
- 顶部筛选栏。
- 内容网格。
- 检查器抽屉。
- 组织面板。
- 批量操作条。
- 导入进度弹窗。
- 预览查看器。
- 回收站。

## 6. 色彩规范

### 6.1 基础色

| Token | 颜色 | 用途 |
| --- | --- | --- |
| `--bg` | `#FAFAFA` | 页面背景 |
| `--surface` | `#FFFFFF` | 卡片、弹窗、菜单 |
| `--line` | `#E4E4E7` | 边框 |
| `--text` | `#18181B` | 主文字 |
| `--muted` | `#71717A` | 次级文字 |
| `--soft` | `#A1A1AA` | 辅助文字 |
| `--danger` | `#DC2626` | 删除、危险 |
| `--success` | `#16A34A` | 完成、恢复 |

### 6.2 使用规则

- 黑白灰用于结构和内容。
- 彩色只用于状态、操作反馈和选中反馈。
- 不使用大面积蓝色、紫色或渐变背景。
- 彩色面积控制在 5% 以内，避免喧宾夺主。

### 6.3 状态反馈

| 状态 | 表现 |
| --- | --- |
| 选中 | 深灰描边 + 勾选角标 |
| 成功 | 绿色提示 |
| 危险 | 红色按钮/菜单 |
| 进行中 | 进度条 + 阶段文字 |
| 错误 | 红色提示 + 可操作说明 |

## 7. 字体规范

### 7.1 字体

统一使用无衬线字体：

```text
Inter, ui-sans-serif, system-ui, "PingFang SC", "Microsoft YaHei"
```

### 7.2 字号层级

| 级别 | 字号 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面标题 | 15-16px | 700 | 当前视图 |
| 区块标题 | 13px | 700 | 文件夹、标签、检查器 |
| 正文 | 12-13px | 400-500 | 作品名、页面名 |
| 辅助 | 11px | 400 | 标签、时间、大小、说明 |

不通过大量字号差异制造层级，而是通过颜色、字重和留白控制层级。

## 8. 布局规范

### 8.1 网格

- 基础间距：4 / 8 / 12 / 16 / 20 / 24px。
- 卡片圆角：8px。
- 内容网格间距：12px。
- 主内容网格使用自适应列，优先保证内容宽度。

### 8.2 视觉流程

作品库采用 F 型：

```text
左上：当前视图 + 筛选
右上：导入/批量操作
左侧：浏览网格
右下：选中后详情抽屉
```

灵感集采用 Z 型：

```text
左上：当前路径
右上：筛选/导入
中部：图片网格
右下：选中后预览
```

### 8.3 移动端

- 默认单列。
- 主导航收窄为图标栏。
- 组织面板和检查器使用底部抽屉。
- 不出现横向滚动。

## 9. 交互规范

| 原则 | 落地方式 |
| --- | --- |
| 一致性 | 所有弹窗、菜单、按钮统一黑白灰和 8px 圆角 |
| 快捷键 | Cmd/Ctrl+Z 撤销，Cmd/Ctrl+Shift+Z 重做，Cmd+A 全选，Delete 删除，Esc 关闭 |
| 反馈 | 每次操作显示 Toast、进度或选中态 |
| 清晰结束点 | 导入、批量操作、回收站操作都有明确完成状态 |
| 错误处理 | 错误提示说明原因和下一步 |
| 撤销 | 文件夹、标签、页面、回收站均支持可逆操作 |
| 控制感 | 所有抽屉、弹窗、批量条都可以手动关闭 |
| 减少记忆负担 | 当前筛选、当前选中、当前文件夹都直接显示在界面中 |

## 10. 实施阶段

### Phase 1：布局简化

目标：默认两栏。

- 删除作品库左侧管理栏。
- 删除灵感集常驻文件夹栏。
- 检查器改为抽屉，默认关闭。
- 顶部筛选栏统一。

验收：

- 1440px 下主内容区宽度不低于 65%。
- 默认最多两栏。
- 作品库和灵感集移动端无横向溢出。

### Phase 2：组织面板

目标：文件夹和标签统一管理。

- 新建组织面板。
- 迁移文件夹树。
- 迁移标签树。
- 支持页面拖拽到文件夹。
- 删除重复入口。

验收：

- 文件夹和标签只在组织面板中管理。
- 顶部标签只负责筛选。
- 所有既有文件夹/标签功能仍可用。

### Phase 3：批量操作收敛

目标：多选后只出现一条清晰路径。

- 多选后显示顶部批量操作条。
- 检查器不再重复完整批量面板。
- 右键菜单只保留快捷操作。

验收：

- 批量加分类、加标签、移动、评分、导出、回收站均可用。
- 批量操作条不遮挡内容。

### Phase 4：视觉与交互收口

目标：统一色彩、字体、反馈和移动端。

- 补充状态色。
- 统一字体层级。
- 统一弹窗、菜单、抽屉动效。
- 优化空状态、错误状态、加载状态。

验收：

- 全站黑白灰统一。
- 彩色只用于状态。
- 所有操作都有反馈。

### Phase 5：回归与上线

- 备份 `data/app.db` 和 `storage/`。
- 跑 `npm run lint`、`npm run build`、`npm run smoke`、`npm run acceptance`。
- 回归上传、预览、动图、文件夹、标签、回收站、拖拽、多选、撤销。
- 完成飞书环境部署和线上回归。

## 11. 不破坏现有功能

这次整改是“收敛入口”，不是“删除能力”。必须保留：

- 作品库筛选、排序、收藏、批量操作。
- 灵感集页面筛选、多选、拖拽、动图播放。
- 文件夹新建、重命名、删除、拖拽、持久化。
- 标签分组、删除、筛选、计数。
- 回收站恢复、永久删除、清空、预览。
- 导入进度、多文件导入、GIF、封面/封底标签。

## 12. 最终验收

- 默认界面最多两栏。
- 文件夹和标签有唯一管理入口。
- 检查器按需打开。
- 导入作品只有一个全局主入口。
- 作品卡片信息完整但不拥挤。
- 移动端不破版。
- 所有操作可撤销或可恢复。
- 所有回归测试通过。
