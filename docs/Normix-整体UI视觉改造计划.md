# Normix 整体 UI 视觉改造计划

## 1. 目标

参考现代 Dashboard 风格，把 Normix 从当前偏功能的界面，升级为更规范、更洋气、更高级的整体视觉系统，同时不破坏现有作品库、灵感集、标签管理、回收站等功能。

核心目标：

- 建立统一的视觉规范。
- 统一间距、圆角、颜色、字体、图标、阴影。
- 优化首页、作品库、灵感集、标签管理、回收站等核心页面。
- 使用 undraw 等开源矢量插画补充空状态和引导场景。
- 通过“改造 - 评估 - 迭代 - 验收”多轮推进。

## 2. 当前情况评估

### 2.1 已具备的基础

- 已有明确产品结构：首页、作品库、灵感集、标签管理、回收站。
- 已有 Normix 品牌、首页统计、作品卡片、文件夹树、标签树等核心能力。
- 已有收缩侧边栏、文件上传、拖拽、右键菜单等交互。
- 已有黑白灰主视觉，具备进一步规范化的基础。

### 2.2 当前主要问题

| 区域 | 问题 |
| --- | --- |
| 全局视觉 | 圆角、阴影、间距不统一，部分页面仍偏“功能型” |
| 侧边栏 | 结构完整，但品牌区、导航区、底部操作区层级不够精致 |
| 首页 | 内容多，部分区域信息密度与留白比例不够稳定 |
| 作品库 | 卡片、筛选栏、检查器视觉一致性可继续优化 |
| 灵感集 | 文件夹、页面网格、检查器之间的视觉关系需要更统一 |
| 标签管理 | 已改成独立页面，但视觉细节仍可继续打磨 |
| 回收站 | 列表与空状态已迭代，还需与整体视觉系统统一 |
| 空状态 | 各页面空状态风格不完全统一，可统一使用插画 |

## 3. 目标视觉方向

### 3.1 整体风格

- 干净、克制、高级的 Dashboard 风格。
- 以白色和浅灰为主，黑色为强强调色，少量彩色用于数据和状态。
- 不用大面积渐变、不用重阴影、不用复杂装饰。

### 3.2 设计基础

**颜色**

- 主背景：`#ffffff`
- 页面背景：`#fafafa`
- 主文字：`#18181b`
- 次要文字：`#71717a`
- 弱化文字：`#a1a1aa`
- 边框：`#ececee / #e4e4e7`
- 强调色：`#3e6df0`
- 成功：`#0f9d8e`
- 警告：`#f59e0b`
- 危险：`#dc2626`

**圆角**

- 小控件：`8px`
- 卡片：`10px`
- 大面板：`12px`
- 弹窗/抽屉：`14px`
- 胶囊：`999px`

**间距**

- 基础间距：`4px`
- 内容间距：`8px / 12px / 16px / 20px / 24px`
- 页面边距：`20px - 28px`

**字体**

- 系统字体栈保持不变。
- 标题：`18px - 24px`
- 正文：`13px - 14px`
- 辅助：`11px - 12px`
- 数字/数据：加粗，强调层级。

**阴影**

- 常态：`0 1px 2px rgba(24, 24, 27, 0.04)`
- 悬浮：`0 10px 24px rgba(24, 24, 27, 0.08)`
- 浮层：`0 20px 50px rgba(24, 24, 27, 0.14)`

**图标**

- 统一使用 `lucide-react`。
- 按钮中优先图标 + 文字。
- 工具栏图标统一尺寸：`14px - 16px`。

## 4. 插画策略

### 4.1 来源

- 使用 [undraw.co](https://undraw.co/illustrations) 等开源矢量插画站点。
- 优先选择简洁、现代、低饱和度的插画。
- 插画下载后统一放入 `public/illustrations/`。

### 4.2 使用场景

| 场景 | 插画建议 |
| --- | --- |
| 回收站空状态 | 回收/整理类插画 |
| 作品库无搜索结果 | 搜索/空结果插画 |
| 灵感集无页面 | 图片/灵感类插画 |
| 首页欢迎区 | 品牌感插画 |
| 标签管理空状态 | 标签/分类插画 |

### 4.3 使用原则

- 插画只用于空状态、欢迎区和必要的引导场景。
- 不作为页面背景铺满。
- 插画尺寸统一，不拉伸变形。
- 文字与插画不重叠。
- 不使用复杂、花哨、低质量的装饰图。

## 5. 页面改造范围

### 5.1 全局框架

- 重构侧边栏视觉：
  - 品牌区更精致。
  - 导航项 hover/active 状态统一。
  - 收缩态更协调。
  - 上传入口更突出但不突兀。
- 增加统一顶栏视觉规范：
  - 页面标题。
  - 搜索框。
  - 主操作按钮。

### 5.2 首页

- 欢迎 Banner：
  - 使用更高级的排版。
  - 插画作为局部配图，不铺满。
  - 文案、按钮、数据比例更稳定。
- 数据卡片：
  - 统一尺寸、图标、圆角。
  - 数据与说明层级清晰。
- 图表：
  - 统一配色。
  - 减少视觉噪音。
- 最近上传：
  - 卡片布局统一。

### 5.3 作品库

- 筛选栏：
  - 统一按钮、下拉、标签样式。
- 作品卡片：
  - 统一封面比例、标题、元信息。
- 检查器：
  - 统一标签、评分、操作按钮。
- 空状态：
  - 使用统一插画。

### 5.4 灵感集

- 文件夹面板：
  - 与标签树、文件树视觉统一。
- 页面网格：
  - 保持图片展示优先。
- 检查器：
  - 与作品库检查器统一。
- 空状态：
  - 使用图片/灵感类插画。

### 5.5 标签管理

- 独立页面保持文件夹式结构。
- 标签树、新建输入、右键菜单视觉统一。
- 空状态使用插画。

### 5.6 回收站

- 空状态：
  - 使用回收站插画。
  - 标题、操作、提示、底部信息完整。
- 有数据状态：
  - 保持列表式管理界面。
  - 与整体视觉统一。

## 6. 改造、评估、迭代流程

### 第 0 轮：基线评估

- 对每个核心页面截图。
- 列出视觉不一致问题。
- 建立统一设计 Token。
- 输出当前问题清单。

验收：

- 每个页面都有明确问题记录。
- 设计 Token 已统一。

### 第 1 轮：全局框架改造

- 改造侧边栏。
- 统一顶栏结构。
- 统一按钮、输入框、下拉、标签、卡片样式。
- 统一间距、圆角、阴影。

验收：

- 全局基础组件视觉一致。
- 侧边栏展开/收缩正常。

### 第 2 轮：首页与核心页面

- 首页整体视觉重构。
- 作品库视觉统一。
- 灵感集视觉统一。
- 标签管理视觉统一。
- 回收站视觉统一。

验收：

- 每个页面都符合设计 Token。
- 无重叠、无错位、无过度留白。

### 第 3 轮：插画与空状态

- 从 undraw 选择合适的插画。
- 替换所有核心空状态。
- 统一插画尺寸和位置。
- 首页欢迎区接入插画。

验收：

- 每个空状态都有统一插画。
- 插画与文字不重叠。
- 插画未拉伸变形。

### 第 4 轮：交互与细节

- hover 状态。
- 选中状态。
- 右键菜单。
- 拖拽反馈。
- 空状态过渡。
- 响应式适配。

验收：

- 交互反馈统一。
- 移动端和窄屏无明显破版。

### 第 5 轮：最终验收

逐页对照参考图验收：

1. 页面是否规范。
2. 是否洋气、高级。
3. 是否干净、不杂乱。
4. 是否保留功能完整性。
5. 是否与现有黑白灰风格统一。

自动验收：

- `npm run lint`
- `npm run build`
- `npm run smoke`
- `npm run acceptance`

## 7. 每轮评估方式

每轮改造后都执行：

1. 浏览器截图对比。
2. 页面结构检查。
3. 视觉一致性检查。
4. 交互流程测试。
5. 自动回归测试。

评分维度：

- 布局规范：`1-5`
- 视觉高级感：`1-5`
- 信息清晰度：`1-5`
- 交互一致性：`1-5`
- 功能完整性：`1-5`

每轮目标：

- 单项不低于 `4`。
- 平均分不低于 `4.5`。
- 若低于目标，进入下一轮迭代。

## 8. 风险与控制

| 风险 | 控制方式 |
| --- | --- |
| 视觉改造破坏功能 | 只改样式和结构，不改数据逻辑 |
| 插画风格不统一 | 只使用 undraw 等统一插画源 |
| 过度装饰 | 插画只用于空状态和欢迎区 |
| 改完后布局错乱 | 每轮浏览器逐页截图验收 |
| 工作量过大 | 按轮次推进，先基础后页面 |

## 9. 最终交付物

- 统一设计 Token。
- 统一组件视觉。
- 全部核心页面改造。
- 统一插画空状态。
- 每轮评估记录。
- 最终验收报告。
